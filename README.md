# Inventory & Expiration Management System

A web-based inventory and expiration management system built with Google Apps Script, Google Sheets, HTML, CSS and JavaScript.

## 📌 About the project

This project was developed to help monitor inventory items and their expiration dates.

The system processes data stored in Google Sheets and provides a web dashboard for monitoring expiration status.

## ⚙️ Features

- 📦 Inventory monitoring
- 📅 Expiration date tracking
- ⚠️ Automatic expiration classification
- 🔎 Item search
- 🔍 Filtering by expiration status
- 📊 Web dashboard
- 🔄 Automatic data processing
- 📋 Expiration reports

## 🛠️ Technologies

- Google Apps Script
- Google Sheets
- JavaScript
- HTML
- CSS

## 📱 Future development

The project is currently functional as a web-based system.

The next development stage is the integration with a mobile application, allowing expiration alerts to be delivered directly to mobile devices through notifications.
